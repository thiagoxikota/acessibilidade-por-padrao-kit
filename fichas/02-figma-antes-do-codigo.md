# Ficha 2. O que entra no Figma antes do código

O Figma registra a intenção. A prova é no navegador.

## Checklist

### Biblioteca
- [ ] Cores documentadas **em pares aprovados**: texto e fundo juntos, nas variáveis.
- [ ] Nenhuma cor solta fora dos pares.
- [ ] Cada par com o contraste medido e anotado.

### Componente
- [ ] Estado de foco desenhado, visível sobre qualquer fundo onde o componente aparece.
- [ ] Como funciona no teclado: quais teclas, em que ordem.
- [ ] O que o leitor de tela deve falar (nome, papel, estado).
- [ ] Cada estado: padrão, foco, desabilitado, erro, carregando, vazio.
- [ ] Se tem animação, a versão sem animação.

### Exemplo da documentação
- [ ] O exemplo usa **o mesmo componente** que o produto usa.
- [ ] Nada de cópia solta ou desenho refeito à mão no exemplo.

### Entrega
- [ ] Gravação curta do teste de teclado ([ficha 1](01-teste-de-teclado.md)) volta para a documentação.
- [ ] Quando usar e quando não usar o componente, por escrito.
